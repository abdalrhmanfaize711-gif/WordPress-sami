# دليل التشغيل — رِحلات اليمن على Laragon

هذا المشروع يعمل محليًا باستخدام Laragon: Apache وPHP لتشغيل WordPress، وMySQL لقواعد بيانات WordPress وStrapi، وNode.js لتشغيل لوحة Strapi. الإضافة والربط مكتوبان مسبقًا؛ لا يلزمك تعديل PHP.

## 1. جهز Laragon

1. افتح Laragon واضغط **Start All**.
2. تأكد أن Apache وMySQL يعملان. يستخدم المشروع MySQL على المنفذ `3306` وApache على المنفذ `80`.
3. يتطلب Strapi Node.js LTS 22 أو 24. فحص هذا الجهاز وجد Node.js 24.21 وPHP 8.3 مع إضافات MySQL.

إذا كان Apache أو MySQL لا يبدأ، راجع المنفذ المستخدم في Laragon قبل متابعة الإعداد.

## 2. جهز ملفات الموقع وقواعد البيانات

افتح PowerShell في مجلد المستودع ثم شغّل:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install-laragon.ps1
```

سيطلب كلمة مرور حساب MySQL `root`. في Laragon الافتراضي غالبًا لا توجد كلمة مرور؛ اضغط Enter إن لم تكن قد وضعت كلمة مرور. يقوم الإعداد تلقائيًا بـ:

- تنزيل WordPress الرسمي إلى `C:\laragon\www\yemen-travel` إذا لم يكن مثبتًا هناك.
- إنشاء قاعدتي `yemen_wordpress` و`yemen_strapi` دون حذف أي قواعد موجودة.
- تجهيز `wp-config.php` محليًا، مع السماح المحدود للإضافة بالاتصال بـStrapi عبر `127.0.0.1:1337`.
- نسخ إضافة الموقع إلى مجلد إضافات WordPress.
- إنشاء إعداد Strapi المحلي في `strapi/.env` وتثبيت اعتماد MySQL وحزم Strapi.

لا يبدل الإعداد ملفات WordPress المثبتة إذا وجد `wp-settings.php`. إذا كان المجلد موجودًا لكنه ليس تثبيت WordPress، يتوقف بدل الكتابة فوق ملفاته.

## 3. أكمل إعداد WordPress

افتح [http://localhost/yemen-travel](http://localhost/yemen-travel)، اختر العربية، وحدد اسم الموقع وحساب المدير. الإضافة ستظهر من البداية ضمن **الإضافات ← الإضافات المنصّبة**. فعّل **Yemen Travel — Yemen Tourism**.

إذا ظهر خطأ اتصال قاعدة البيانات، أعد تشغيل الإعداد وأدخل كلمة مرور MySQL الصحيحة. بيانات الاتصال الافتراضية للموقع هي قاعدة `yemen_wordpress` والمستخدم `root` على `127.0.0.1:3306`.

## 4. شغّل Strapi

افتح نافذة PowerShell ثانية، من مجلد المستودع، ونفّذ:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start-laragon-strapi.ps1
```

اترك النافذة مفتوحة أثناء استخدام الموقع. افتح [http://127.0.0.1:1337/admin](http://127.0.0.1:1337/admin) وأنشئ حساب مدير Strapi.

من **Settings → API Tokens → Create new API Token** أنشئ رمزًا بصلاحية **Read-only**. انسخه فورًا واحفظه بمكان خاص؛ لن تعرضه Strapi مرة أخرى بعد إغلاق صفحة الإنشاء.

## 5. اربط WordPress بـStrapi

في WordPress افتح **الإعدادات ← Yemen Travel** وأدخل:

- عنوان Strapi: `http://127.0.0.1:1337`.
- رمز القراءة الذي أنشأته في Strapi.
- مدة التخزين المؤقت: `0` أثناء إدخال البيانات والاختبار.

احفظ الإعدادات. يتصل WordPress بـStrapi من جهة الخادم، والرمز لا يظهر للزوار.

## 6. أضف المحتوى واعرض الموقع

أنواع المحتوى الجاهزة في Strapi هي **إعدادات الموقع السياحي** و**الوجهات السياحية**. استخدم [data/demo-content.json](../data/demo-content.json) لإدخال محتوى سقطرى وصنعاء القديمة وشبام وعدن. أنشئ السجلات واحفظها ثم اضغط **Publish** لكل سجل. أدخل رابط الصورة واسم المصور ومصدر الصورة ورابط الترخيص؛ الصور من الإنترنت وتحتاج اتصالًا لعرضها.

في WordPress أنشئ صفحة «الرئيسية»، وأضف كتلة **Shortcode** بهذا النص، ثم انشرها:

```text
[yemen_travel_home]
```

من **الإعدادات ← القراءة** اختر «صفحة ثابتة» وحدد «الرئيسية». يمكن إنشاء صفحة وجهات مستقلة باستعمال:

```text
[yemen_destinations]
```

## 7. اختبار الربط

- افتح [الموقع المحلي](http://localhost/yemen-travel) وتأكد من ظهور الصفحة.
- افتح [لوحة Strapi](http://127.0.0.1:1337/admin) وتأكد من إمكانية الدخول.
- انشر وجهة في Strapi ثم تحقق من ظهورها في WordPress. مع مدة التخزين المؤقت `0` يظهر التغيير عند إعادة تحميل الصفحة.
- إذا لم يعمل Strapi، راجع رسالة الخطأ في نافذة PowerShell التي تشغّله. إذا لم يتصل MySQL، تأكد من أن Laragon شغّل MySQL على `3306`.

لإيقاف Strapi اضغط `Ctrl+C` في نافذته. أوقف Apache وMySQL من Laragon بزر **Stop All**. لا تحذف مجلد `C:\laragon\data\mysql-8.4`؛ يحتوي قواعد البيانات.

## Docker بديل

يظل `docker-compose.yml` متاحًا لمن يريد التشغيل عبر Docker. مع Laragon لا تشغّل Docker Compose؛ يستخدم Strapi إعداد MySQL المحلي الذي أنشأه سكربت Laragon.

## النشر العام

هذه الإعدادات محلية ولا تنشر الموقع للإنترنت. عند النشر تحتاج إلى استضافة WordPress وStrapi، ونطاق وHTTPS، وقواعد بيانات دائمة ونسخ احتياطية. لا تستخدم إعدادات Laragon أو كلمة مرور root على خادم عام. راجع روابط الصور ومصادر المعلومات وإرشادات السفر الرسمية دوريًا؛ الموقع تعريفي ولا يضمن سلامة السفر أو إمكانية الوصول إلى أي منطقة.
